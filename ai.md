# How I used AI (Claude)

I used Claude, Anthropic's AI assistant, as a helper while building VerifyDesk:

- **Research:** comparing the available tools and services for handling voice (speech-to-text, text-to-speech, local
  and cloud AI models) and finding free options that fit the challenge.
- **Coding:** building the code base, and support while developing and fixing problems found during testing.
- **Fictional data:** creating the made-up company, employees, devices, sign-in history and the scripted calls.
- **Formatting:** formatting the code and documents, such as the README, for a clearer structure.
